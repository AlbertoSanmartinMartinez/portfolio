# Decisions

One file, append only. Take the next free number; if two branches take the same one, the second to merge renumbers. Each entry links its plan when there is one, and the plan gets a "Landed in ADR-NNNN" line at its top. Copy the format from [templates/adr.md](templates/adr.md).

## ADR-0001: Adopt the Agentic SDLC harness template

- Date: 2026-11-25
- Status: accepted
- Context: coding agents work on this repo and need the same rules, flow and checks whatever the tool.
- Decision: use the Agentic SDLC harness template (version in `.harness-version`): `AGENTS.md` as the single source, skills and roles in `.agents/`, specs before code, checks in CI.
- Consequences: harness changes need a person's review; template upgrades arrive through `update-harness`.

## ADR-0002: Stack, tracker and hosting

- Date: 2026-11-25
- Status: accepted
- Context: a personal portfolio with a small contact form, built mostly by coding agents, that should also exercise the harness (migrations, generated clients, e2e).
- Decision: Next.js (App Router) in TypeScript with pnpm; PostgreSQL with Drizzle ORM and Drizzle Kit migrations; an OpenAPI contract for the contact API with a client generated by openapi-typescript; Playwright Test and Vitest; DigitalOcean App Platform with managed PostgreSQL; Linear (team ALB, project "Personal") as the tracker; trunk-based with semver tags published by Alberto.
- Consequences: one deployable app and one database to run; Drizzle Kit has no down migrations, so reverts are forward migrations; App Platform builds from the repository, so no image registry is needed.
