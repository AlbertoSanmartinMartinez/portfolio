# Glossary

Domain language only. Use these terms in specs, code and PRs; add a term here before using a new one. Decisions go to [decisions.md](decisions.md), not here.

| Term | Definition | Name in the code | Not to confuse with |
| --- | --- | --- | --- |
| Spec | What a feature does, with numbered acceptance criteria | `specs/<NNN>-<slug>/spec.md` | Plan (how it is built) |
| Invariant | A rule that must always hold, enforced by a check | `INV-NNN` in `invariants.md` | Guideline (advice, no check) |
| Profile | Who Alberto is: name, headline, summary, location, links | `content/profile` | Experience |
| Experience | A role Alberto held: company, title, dates, highlights | `content/experience` | Project |
| Project | Something Alberto built, with its links and stack | `content/projects` | Experience |
| Contact message | What a visitor sends through the contact form | `contact_message` table | Email (how Alberto may reply) |
| Visitor | Anyone browsing the site; never signs in | — | User (there are no accounts) |
